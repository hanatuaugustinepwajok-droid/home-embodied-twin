# Counterfactual Shadow Twin · 命题方案摘要

**项目名称**：Counterfactual Shadow Twin（原 HomeEmbodied Twin 演进）  
**定位**：面向具身智能的 **AI Value Proven 反事实验证台**（Web Mock，非真机）  
**核心命题**：在同环境种子下，对比 AI World（MAIN）与 Non-AI World（SHADOW），证明语义时效与反事实重规划的产品价值。

---

## 1. 问题理解

家庭具身落地前需回答：关掉「智能策略」会怎样？常见失败可归纳为四类**扰动**（非四套无关功能）：

1. **动态障碍** → 导航卡死与重规划需求  
2. **空间语义过期** → 检索依赖错误房间/物体  
3. **目标遮挡/丢失** → 寻人寻物不闭环  
4. **任务中断** → 缺乏可观测恢复策略  

传统数字孪生多为状态监控；本方案把问题转成**可消融的对照实验**。

---

## 2. 方案总览

| 层 | MAIN（AI） | SHADOW（基线） |
|----|------------|----------------|
| 地图 | 动态语义地图 | 静态占用栅格 |
| 时效 | 置信度衰减 + 再观测动机 | 无时效更新 |
| 规划 | 反事实重规划 / 绕行 | 原路径硬闯 → STALLED |
| 验证 | 成功 + 代价更低 | 失败 + 无效代价膨胀 |

统一快照驱动 UI / 3D / 指标；单一 50ms tick 同步广播扰动，**策略响应分化**。

---

## 3. 数字孪生如何验证（Demo）

**一键反事实验证**：开对比 → 同任务 → 注入干扰 → SHADOW 红失败 / MAIN 绿重规划 → Insight 三行定格 → 可选导出结论。

**Insight 定稿**（面试可背）：

1. 扰动：障碍 / 遮挡  
2. 反事实：若关闭语义重规划 → STALLED @ 房间  
3. 收益：少走 Xm / 成功率 0%→100%  

顶栏 `seed` 可复制并「同条件再跑」，证明非偶发 Demo。

---

## 4. 预期收益

- **可论证**：不是「演示成功动画」，而是 AI on/off 的对照结论。  
- **可消融**：能力开关矩阵定位价值来源。  
- **可投递**：三行 Insight + 导出文本 + 一屏录屏即可进作品集。  
- **可演进**：Mock 契约保留，后续可替换为真实 SLAM / VLM / ReID。

---

## 6. 风险与边界（诚实卡）

- 本平台为 **Web Mock**，非真实硬件闭环。  
- SHADOW 失败是 **ablation-by-design**，用于反事实归因，而非声称物理仿真完备。  
- 指标中部分 SHADOW 基线为自洽推导，需在答辩中说明。
